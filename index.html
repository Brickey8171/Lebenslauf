Fertig – jetzt speichern

Hinweis: Diese Vorlage ist für das PDF optimiert. In der Word-Datei erscheint sie vereinfacht (ohne Balken, Symbole und Sonderformen).

So klappt das PDF-Speichern
  1. Klicke auf „Als PDF speichern“. Der Druckdialog deines Browsers öffnet sich.
  2. Wähle als Drucker „Als PDF speichern“ (Chrome/Edge) bzw. unten links „PDF“ → „Als PDF sichern“ (Mac/Safari).
  3. Papier: A4. Ränder: Standard. Hake „Hintergrundgrafiken“ an, damit Farbflächen mitgedruckt werden.
  4. Auf „Speichern“ klicken – fertig.
